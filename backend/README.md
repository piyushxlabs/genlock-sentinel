# Genlock Sentinel — Backend Runtime

Autonomous telemetry-driven SRE and frame-sync integrity agent for In-Camera Visual Effects (ICVFX) on Unreal Engine nDisplay LED-volume stages.

Built with Google Agent Development Kit (ADK) 2.x, Gemini 3.1 Pro (Reasoning), Gemini 3.7 Flash (Triage & HITL), Grafana MCP Server (Prometheus/Loki/Tempo), and Cloud SQL PostgreSQL / local SQLite asyncpg/aiosqlite checkpointing.
